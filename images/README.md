# Screenshots

Real screenshots from Roblox Studio for the tricky steps. Drop a PNG here with the exact
filename below and it appears in the lesson automatically. Until then the lesson shows a
labelled placeholder saying which file to add.

On a Mac, press **Cmd + Shift + 4**, drag a box around the area, and it saves to your Desktop.
Rename it to the filename in the list, then move it into this `images/` folder.
