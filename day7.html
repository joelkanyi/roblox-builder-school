1The big idea

A variable: a labelled box for a number

First, one small word: variable. Do not be scared of it. A variable is just a labelled box that holds a number the game remembers. Think of a jar in the kitchen with a paper label that says Wins. Right now the jar holds 0. Later we drop one more in, and it holds 1. The label never changes. The number inside can grow.

2The backstage brain

Add a Script in ServerScriptService

The scoreboard is a game rule, not a block rule. Game rules live in a special place called ServerScriptService. Think of it as the game's backstage brain. The player never sees it. The game keeps its own rules there. We put our scoreboard code inside it.

3When a player joins

When a player joins, make a scoreboard folder

Now type, one piece at a time. First we need the players. Type this line:

NEW LINE
local Players = game:GetService("Players")

Read it: "Give me the list of Players in this game. Call it Players." Now the "when a player joins" part. PlayerAdded means "when a new player joins the game, do this." Add these lines:

NEW LINES
Players.PlayerAdded:Connect(function(player)
    local leaderstats = Instance.new("Folder")
    leaderstats.Name = "leaderstats"
    leaderstats.Parent = player
end)

Instance.new("Folder") makes a new folder by code, like getting a fresh empty envelope. We name it leaderstats. That name is magic: Roblox looks for a folder with that exact name and shows it on the scoreboard. Then we give the folder to the player.

Spell it leaderstats, all small letters, no space. Roblox only shows the scoreboard if the name is exactly right.

🍌 BRAIN SNACK: A variable remembers a number

A variable is a named box that remembers a number for the game. Our box is named Wins. The game keeps that number safe, even while the player runs and jumps. When you want to change the score, you just change what is in the box.

4Add the Wins box

Put a "Wins" number in the folder, starting at 0

The folder is empty. Now we put the Wins box inside it. An IntValue is a box that holds a whole number (Int is short for a whole number, like 0, 1, 2, no halves). Add these lines before the end), so they are inside the function:

NEW LINES
    local wins = Instance.new("IntValue")
    wins.Name = "Wins"
    wins.Value = 0
    wins.Parent = leaderstats

Read it: "Make a new whole-number box. Name it Wins. Start it at 0. Put it inside the leaderstats folder." The word on the scoreboard will be Wins, because that is the name. Here is the whole backstage Script now:

local Players = game:GetService("Players")

Players.PlayerAdded:Connect(function(player)
    local leaderstats = Instance.new("Folder")
    leaderstats.Name = "leaderstats"
    leaderstats.Parent = player

    local wins = Instance.new("IntValue")
    wins.Name = "Wins"
    wins.Value = 0
    wins.Parent = leaderstats
end)

🍌 BRAIN SNACK: leaderstats is the magic folder

leaderstats is a special folder name. Roblox is always watching for it. When it sees a folder called leaderstats inside a player, it shows the boxes inside it on the top-right scoreboard. Any other name and nothing shows. The name is the magic word.

6The finish block

Put a script on your finish block: add 1 to Wins

The 0 needs to grow. We put a second, small script inside your finish block (the block a player reaches to win). This one lives in the block, not backstage. Make a Script inside your finish block, delete everything, and type this:

NEW SCRIPT
local finish = script.Parent

finish.Touched:Connect(function(otherPart)
    local player = game.Players:GetPlayerFromCharacter(otherPart.Parent)
    if player then
        player.leaderstats.Wins.Value = player.leaderstats.Wins.Value + 1
    end
end)

Read it: "This block is finish. When something touches me, find out which player it was. If it really is a player, open their Wins box and make it 1 more than it was." The if player then check is polite: it makes sure a real player touched it, not a falling brick.

Spell Wins the same as before, capital W. If the finish script says Wins but the backstage script named it wins, they will not match.

Your turn

  2. Delete everything inside it.
  3. Type the script above.
  4. Check Wins is spelled the same in both scripts.
🍌 BRAIN SNACK: Spell the name the same everywhere

The name "Wins" must be spelled the same in every place: in the backstage script that makes it, and in the finish script that adds to it. Wins, wins, and WINS are three different words to the computer. One box, one spelling, everywhere.

No scoreboard, or Wins does not grow? Tap here, do not panic
  1. No scoreboard at all? Check the backstage script is in ServerScriptService, not Workspace. Check the folder name is spelled exactly leaderstats, all small letters, no space.
  2. Wins shows but stays 0? Check the finish script is inside your finish block. Check Wins is spelled the same in both scripts (capital W in both).
  3. Look for red text in the Output window. Red text is the computer helping you. It points at the exact line with the problem. Check that line for a small letter that should be a capital.
🍌 BRAIN SNACK: Games remember with variables

Coins, health, points, lives, gems: every one of them is a variable, a labelled box holding a number. Add to it, take from it, show it on the screen. You now know the trick behind every score in every game. It is just boxes with numbers, changing.
