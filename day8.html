3Find the player

When touched, find the player's body

Open the Script. Delete everything inside. First, name the pad. Then say "when you are touched, look at what touched you." Type this:

NEW
local pad = script.Parent

pad.Touched:Connect(function(otherPart)
    local humanoid = otherPart.Parent:FindFirstChildWhichIsA("Humanoid")
end)

A Humanoid is the player's body. It is the part that can walk and jump. This line looks for a Humanoid on the thing that touched the pad. If a real player stepped on it, it finds one. If a ball or a wall touched it, it finds nothing.

Careful: capital T in Touched, capital C in Connect, and "Humanoid" spelled just like that inside the quote marks.

Your turn
  1. Type these lines yourself.
  2. Go slow. Get the capital letters right.

This is the same touch trick from the lava! 🌋

🍌 BRAIN SNACK: WalkSpeed is just a number

WalkSpeed is not magic. It is a number sitting on the player, like the price on a shop item. You can read it, and you can change it. Change it to a big number and the player runs fast. That is all a speed pad is.

4Go fast

Change WalkSpeed to 50

Now the fun part. If we found a Humanoid, make it fast. Add these lines inside, so it looks like this:

NEW LINES
    if humanoid then
        humanoid.WalkSpeed = 50
    end

if humanoid then means "only if we really found a player's body." This keeps it safe. A ball or a wall has no Humanoid, so nothing happens to them. Only a real player gets the speed. Here is your whole script now:

local pad = script.Parent

pad.Touched:Connect(function(otherPart)
    local humanoid = otherPart.Parent:FindFirstChildWhichIsA("Humanoid")
    if humanoid then
        humanoid.WalkSpeed = 50
    end
end)
Your turn
  1. Add the three new lines.
  2. Check your script matches the big one above.
  3. Read it out loud like a story.

"When my pad is touched, find the player. If there is a player, make them run at 50."

🍌 BRAIN SNACK: Same pattern, new ending

Look close. This is the SAME "when touched, do Y" pattern as the lava on Day 3. The only thing that changed is the Y. Lava said "hurt them." The pad says "speed them up." One pattern powers a hundred different game things. You just swap the ending.

No speed? Tap here, do not panic
  1. Is the Script INSIDE the pad? Check the Explorer. The Script must sit under your pad (Step 2), not next to it. If it is wrong, drag it onto the pad.
  2. Look for red text in the Output window. Red text is the computer HELPING you. It points at the line with the problem. Check that line for a tiny typo: a small letter that should be capital (Touched, Connect, WalkSpeed), or a spelling slip in "Humanoid".
6Bonus

Bonus: make a slow pad, or a jump pad

You know the trick now. Change the ending and you get a new pad. Make a second pad and try one of these:

-- slow mud pad
        humanoid.WalkSpeed = 6

-- super jump pad
        humanoid.JumpPower = 120

A slow pad uses a small number like 6, so the player crawls. A jump pad changes JumpPower instead, so the player jumps way up high. Same trick, brand new pad.

🍌 BRAIN SNACK: One pattern, many games

The lava, the speed pad, the mud pad, the jump pad. All four are the same "when touched, do Y." Only the Y changes. When you see a big game, look for this pattern hiding inside. It is almost always there.
