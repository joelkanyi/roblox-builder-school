3The new idea

First we must find the player

Here is the new idea for today. When something touches your lava, the code must ask: "Is this a PLAYER? Or is it just a rock or a wall?" Not everything that touches the block is a player. So step one inside the box is always: find the player's body first. If we find one, we do the burn. If not, we do nothing.

🍌 BRAIN SNACK: Not everything that touches is a player

Your lava can be touched by many things. A wall next to it. A tree that falls. Another block. The code must check first, like a guard at the school gate who asks "Are you a student?" before letting you in. Only a real player gets burned.

Your turn
  1. No typing now!

4Lines 2 to 4

Build the box that finds the player

Now we make the box of steps, the function. Same as Day 2. This time the first thing inside is: look for the player's body. Add these lines under Line 1:

NEW LINES
local function onTouch(otherPart)
    local character = otherPart.Parent
    local humanoid = character:FindFirstChildWhichIsA("Humanoid")

Read it slow, two small steps:

Line 2: otherPart is the thing that touched the lava. Maybe it is a player's foot. The whole player body is its Parent. We call that body character.

Line 3: we look inside the character for a Humanoid. The Humanoid is the part of a player that controls their health. Only players have one. We use FindFirstChildWhichIsA("Humanoid") to go and look for it.

Watch the two dots! otherPart.Parent uses a dot. character:FindFirstChildWhichIsA uses a colon ( : ), not a dot.

Your turn
  1. Type these lines under Line 1.
  2. Copy the long word FindFirstChildWhichIsA letter by letter. Take your time.
  3. Check every capital letter: F, F, C, W, I, A.

This box is not finished yet. We add the burn next.

🍌 BRAIN SNACK: The Humanoid is the health part

A player is made of many parts: legs, arms, a head. One hidden part is the Humanoid. It holds the player's health and lets them walk and jump. A wall has no Humanoid. So if we find a Humanoid, we KNOW we touched a real player.

5Lines 5 to 7

If it is a player, send them back

Now we finish the box. We only burn if we really found a player. Add these lines inside the function:

NEW LINES
    if humanoid then
        humanoid.Health = 0
    end
end

if humanoid then means "only do the next line if we really found a humanoid." If a rock touched the lava, there is no humanoid, so the code skips it. Safe.

Setting humanoid.Health = 0 takes the player's health down to zero. In Roblox that sends the player back to the start. They come back fresh. This is called respawn.

Two end words now! The first end closes the if. The second end closes the box (the function).

Your turn
  1. Type the three lines inside the box.
  2. Then type one more end on its own line to close the box.
  3. Say out loud: "If I found a player, set their health to zero."

Answer: yes! Health zero sends them back to the start.

🍌 BRAIN SNACK: "if" is a gate

The word if is like a gate. It only lets the code through when the answer is yes. "If humanoid then" means "if we really have a player, open the gate and burn them." No player, gate stays shut, nothing happens. This keeps your game from breaking.

6Connect and Play

Connect the wire. Then walk into the lava. 🔥

The box is ready. Now we wire it to the Touched alarm, the same last line as Day 2. Add this at the very bottom:

NEW LINE
lava.Touched:Connect(onTouch)

In kid language: "Hey lava! When your Touched alarm rings, open the onTouch box and do what is inside." That plugs the wire from the alarm to the box.

Your whole script now looks like this:

local lava = script.Parent

local function onTouch(otherPart)
    local character = otherPart.Parent
    local humanoid = character:FindFirstChildWhichIsA("Humanoid")
    if humanoid then
        humanoid.Health = 0
    end
end

lava.Touched:Connect(onTouch)

Nothing happened? Tap here, do not panic
  1. Is the Script INSIDE the Lava? Check the Explorer. The Script must sit under Lava (Step 1), not next to it. If it is in the wrong place, drag it onto Lava.
  2. Look for red text in the Output window. Red text is the computer HELPING you. It points at the exact line with the problem. Check that line for a tiny typo. Common ones today: the long word FindFirstChildWhichIsA, the colon ( : ) before it, and the two end words.
  3. Did you touch the lava with your body? Walk right into it. If it is too high or too far, move it lower so your character can reach it.
